# Agro-Mat Research Data Management Platform

## 1. Project objective

Develop a centralized platform for recording, managing,
analysing and reporting agro-mat research data.

## 2. Users

- Administrator
- Researcher
- Viewer

## 3. Main features

- Experiment management
- Treatment management
- Plot and replicate management
- Field observation recording
- Laboratory result recording
- Weather data recording
- Crop performance recording
- Treatment comparison
- Charts and visualisation
- PDF report generation
- Responsive web interface

## 4. Core comparison requirements

The platform should compare treatments using:

- Number of observations
- Mean plant height
- Mean soil moisture
- Mean biomass
- Total yield
- Mean yield
- Standard deviation
- Minimum value
- Maximum value

## 5. Proof-of-concept scope

Included:

- CRUD API
- MongoDB database
- Seed data
- Responsive dashboard
- Charts
- Comparison page
- PDF report

Not included initially:

- Advanced authentication
- IoT sensor integration
- Machine learning
- Offline Flutter application
- Complex approval workflows
