# IoT-Based Smart Soil Monitoring and Fertilizer Recommendation System

A complete IoT agriculture platform for monitoring soil and environmental
conditions and generating crop-specific fertilizer and irrigation
recommendations.

## Technology Stack

### IoT
- ESP32
- RS485 / Modbus RTU
- NPK sensor
- Soil pH
- Soil EC
- Soil moisture
- Soil temperature
- Air temperature and humidity

### Backend
- Node.js
- Express
- TypeScript
- MongoDB
- Mongoose

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

## Project Structure

frontend/   - Web dashboard
backend/    - REST API and recommendation engine
firmware/   - ESP32 firmware
docs/       - Project documentation
